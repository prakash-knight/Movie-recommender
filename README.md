Movie Recommender System 
A content-based movie recommendation system built with Streamlit that suggests similar movies based on user selection.

Features
Smart Recommendations: Get 5 movie recommendations based on content similarity
Poster Display: Automatically fetches movie posters from TMDB API
User-Friendly Interface: Clean and intuitive Streamlit web interface
Real-time Search: Uses TMDB API to search for movie posters

Tech Stack
Frontend: Streamlit
Backend: Python
Libraries: Pandas, Scikit-learn, Requests
API: The Movie Database (TMDB) API

Data Storage: Pickle files for model and data
